This repository collects a series of machine‑learning practices (TP1–TP5) completed for an assignment. Each practice explores a different family of models and techniques.

TP1 – Decision Trees
Uses scikit-learn decision trees to analyze the Hypothyroid dataset and synthetic problems

Experiments with training-set size, noise robustness, and high-dimensional feature spaces on nested-spiral data

TP2 – Multilayer Perceptrons
Employs MLPClassifier and MLPRegressor to study classification and regression tasks

Investigates model capacity, learning-rate and momentum effects, and regularization (weight decay) across multiple datasets

Compares performance in higher-dimensional settings versus decision trees

TP3 – Naive Bayes
Applies Gaussian and histogram-based Naive Bayes classifiers to evaluate dimensionality limits and dataset suitability

Implements a histogram-bin search procedure and extends to text classification with a multinomial model on the 20 Newsgroups dataset

TP4 – k-Nearest Neighbors
Utilizes k-NN for classification and regression, tuning k, comparing uniform vs. distance-weighted voting, and handling noisy nested-spiral data

Explores alternative distance-threshold formulations and outlines a recommendation system based on neighbor similarity

TP5 – Convolutional Neural Networks
Trains a TensorFlow/Keras CNN on CIFAR‑10 following a specified architecture

Studies regularization via dropout, data augmentation, and optional enhancements including improved CNN designs and metric-learning for k-NN classification
